# Блок предохранителей и реле LADA Vesta: подробные схемы и расшифровка

В электросети автомобиля *LADA Vesta* используется современная архитектура с электронным блоком кузовной электроники (EMM / BCM). За защиту цепей от короткого замыкания и перегрузок отвечают два основных монтажных блока: один расположен в салоне, второй — в моторном отсеке.

В данном руководстве представлена подробная расшифровка предохранителей и реле для всех модификаций Лада Веста (седан, SW, Cross, NG).

---

## Где находятся блоки предохранителей?

1. **Монтажный блок в салоне:** Находится с левой стороны торпедо, ниже рулевой колонки. Для доступа необходимо снять пластиковую крышку панельки.
2. **Монтажный блок в подкапотном пространстве:** Расположен в левой части двигательного отсека, рядом с аккумулятором и корпусом воздушного фильтра. Находится под черным пластиковым кожухом на защелках.

## 1. Схема монтажного блока в салоне LADA Vesta

Ниже приведена таблица самых востребованных предохранителей салонного блока.

| № | Номинал | Защищаемая цепь |
| :--- | :--- | :--- |
| **F1** | 15A | Розетка 12V / Прикуриватель (передний) |
| **F2** | 15A | Розетка 12V для задних пассажиров / в багажнике |
| **F12** | 10A | Мультимедийная система (магнитола), панель приборов |
| **F18** | 10A | Обогрев передних сидений |
| **F26** | 15A | Моторчик омывателя лобового стекла |
| **F28** | 20A | Стеклоподъемник передней левой (водительской) двери |
| **F29** | 20A | Стеклоподъемник передней правой двери |
| **F34** | 15A | Обогрев рулевого колеса |
| **F41** | 10A | Задние стоп-сигналы, датчик педали тормоза |

> **Совет:** Для извлечения предохранителей используйте специальные пластиковые пинцеты, которые закреплены на внутренней стороне крышки монтажного блока.

## 2. Схема монтажного блока под капотом

Подкапотный блок содержит силовые предохранители высокой силы тока и основные реле управления силовым агрегатом.

| Обозначение | Номинал | Назначение |
| :--- | :--- | :--- |
| **F50** | 60A | Главный силовой предохранитель цепи питания салона |
| **F51** | 30A/40A | Система ABS / ESP (гидравлический насос) |
| **F53** | 30A | Вентилятор системы охлаждения двигателя (1 скорость) |
| **F54** | 50A | Вентилятор системы охлаждения двигателя (2 скорость) |
| **F58** | 30A | Обогрев лобового стекла (левая сторона) |
| **F59** | 30A | Обогрев лобового стекла (правая сторона) |
| **K1** | Реле | Реле включения компрессора кондиционера |
| **K2** | Реле | Главное реле системы управления двигателем (ЭБУ) |
| **K3** | Реле | Реле бензонасоса |

## Как правильно заменять предохранитель?

1. Выключите зажигание и снимите клемму «минус» с аккумулятора.
2. Снимите крышку соответствующего монтажного блока.
3. С помощью пинцета извлеките перегоревший элемент.
4. Визуально проверьте нить внутри предохранителя: если она разорвана или оплавлена — элемент неисправен.
5. Установите новый предохранитель **строго такого же номинала** (обозначается цветом и цифрой на корпусе).
