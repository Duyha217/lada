# Lada Spravka MVP

Справочник по ремонту и обслуживанию автомобилей LADA.

## Инструкция по развертыванию на Vercel:

1. Распакуйте архив и загрузите все файлы в новый репозиторий на GitHub.
2. Зайдите на Vercel, нажмите **"Add New..." -> "Project"**.
3. Импортируйте ваш GitHub-репозиторий.
4. Нажмите **"Deploy"** (настройки сборки определятся автоматически).

## Как добавлять новые статьи:
Создавайте новые `.md` файлы в папке `src/content/docs/`.
